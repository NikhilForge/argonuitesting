## 🌟 Overview

**Awaken The Legend** is an ultra-premium, interactive 3D WebGL scrolling website. Built with **Argon**, it delivers a cinematic anime visual experience driven by user scroll interactions.

As you scroll through the page, a legendary blade awakens with custom shaders, volumetric lighting, ember particle physics, and dynamic camera choreography powered by GSAP ScrollTrigger.

---

## ✨ Features

- 🗡️ **Procedural 3D Katana & Blade Geometry**: High-precision 3D sword rendering with reflective metalness, hamon blade line, and emissive runes.
- 📜 **Scroll-Driven Cinematic Narrative**: GSAP ScrollTrigger timeline orchestrating camera angles, orbit movements, zoom effects, and text reveals.
- 🔥 **Real-Time Particle Physics**: Floating fiery embers, sparks, and dynamic lighting reacting to scroll velocity.
- 🎨 **Cinematic Shaders & Post-Processing**: Bloom effects, dark void atmosphere, chromatic aberration, and anime aura glows.
- 📱 **Responsive & Mobile-Optimized**: Smooth performance on desktop and mobile viewports with GPU hardware acceleration.
- ⚡ **Zero Build Step**: Fully self-contained single-page application using modern CDNs.

## 🚀 Quick Start / Local Preview

### 1. Clone the Repository

```bash
git clone https://github.com/NikhilForge/argonuitesting.git
cd argonuitesting
```

### 2. Run Locally

Open `index.html` in your browser, or spin up a local development server:

#### Using Python:
```bash
python -m http.server 8000
```
Then visit [http://localhost:8000](http://localhost:8000).

#### Using Node.js:
```bash
npx serve .
```

#### Using VS Code:
Right-click `index.html` and click **"Open with Live Server"**.
