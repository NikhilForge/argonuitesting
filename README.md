## 📖 Overview

**Argon UI Testing** is a dedicated testing suite and visual sandbox built using the **Argon Design System** by Creative Tim. 

Designed for rapid UI validation, component stress-testing, and responsive layout prototyping, this project brings together handcrafted UI components, sleek gradients, and versatile dashboard widgets to test visual integrity and interaction flows across various viewports.

---

## ✨ Features

- 🎨 **Argon Design Language**: Pre-styled gradients, modern cards, refined typography, and soft box-shadows.
- 📱 **Fully Responsive**: Fluid grid system built to adapt seamlessly across mobile, tablet, desktop, and ultra-wide screens.
- ⚡ **Component Testing Ground**:
  - **Stat Cards & Metrics**: Real-time KPI summaries with trend badges and vector icons.
  - **Form Controls & Inputs**: Custom validation states, floating labels, input groups, and switches.
  - **Interactive Modals & Alerts**: User feedback banners, notification toasts, and popovers.
  - **Data Tables**: Clean data representation with badges, status pills, and action menus.
  - **Navigation Bars**: Responsive sticky topbars, search bars, and user profile menus.
- 🌙 **Theming Ready**: Modular CSS variables for primary palettes, accent gradients, and dark/light mode adjustments.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/NikhilForge/argonuitesting.git
cd argonuitesting
```

### 2. Run Locally

You can preview the project with any local web server:

**Using Python:**
```bash
python -m http.server 8000
```
Then visit [http://localhost:8000](http://localhost:8000) in your browser.

**Using Node.js:**
```bash
npx serve .
```

**Using VS Code:**
Right-click on `index.html` and select **"Open with Live Server"**.

## 🧪 UI Testing Checklist

- [x] **Grid Alignment**: Verify column wrapping across breakpoints (`xs`, `sm`, `md`, `lg`, `xl`).
- [x] **Form States**: Hover, active, focus-visible, and disabled input styling.
- [x] **Button Hierarchy**: Primary, secondary, danger, outline, and pill variants.
- [x] **Modal & Dropdown Interactions**: Correct z-index layering and backdrop transitions.
- [x] **Cross-Browser Compatibility**: Verified on Chrome, Firefox, Edge, and Safari.
